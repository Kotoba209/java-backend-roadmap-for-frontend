## 学习目标

学完整套资料后，应具备以下能力：

- 能使用 Java 编写基础业务代码。
- 能使用 MySQL 设计业务数据表并编写 SQL。
- 能使用 Spring Boot 开发 RESTful 接口。
- 能使用 MyBatis / MyBatis-Plus 完成数据库访问。
- 能实现统一响应、参数校验、全局异常和日志记录。
- 能实现登录认证、JWT、角色权限和接口权限控制。
- 能完成文件上传、接口文档、Redis 缓存等常见后端能力。
- 能将 Java 后端项目打包并通过 Docker / Nginx 部署上线。
